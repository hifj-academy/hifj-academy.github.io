## ✏️ নিজে সম্পাদনা (লেখা বদলানো) — ৫ ধাপ

1. কম্পিউটারে এই পাতায় থাকা অবস্থায় কীবোর্ডে **`.`** (ফুলস্টপ) চাপুন। ব্রাউজারেই একটি সম্পাদক খুলবে।
2. বাঁ দিকের তালিকা থেকে পাতাটি খুলুন (যেমন `contact.html`)।
3. **Ctrl + F** চেপে `সম্পাদনা:` লিখুন। প্রতিটি বদলানোর জায়গার ঠিক আগে এই চিহ্ন আছে।
4. শুধু বাংলা লেখাটুকু বদলান। `<` `>` চিহ্নের ভেতরের কিছু মুছবেন না।
5. বাঁ দিকের তৃতীয় আইকন (Source Control) → উপরে একটি বার্তা লিখুন → **Commit & Push** চাপুন।

৫ মিনিট পর সাইট খুলে **Ctrl + Shift + R** চাপলে পরিবর্তন দেখবেন।

> 💡 **সব পাতায় একসাথে বদলাতে** (যেমন ফোন নম্বর): ধাপ ৩-এ **Ctrl + Shift + H** চাপুন → উপরে পুরোনো লেখা, নিচে নতুন লেখা → **Replace All**।

## 🖼️ ছবি বদলানো

1. নতুন ছবির নাম **হুবহু পুরোনোটার মতো** রাখুন (যেমন `campus.jpg`)।
2. এই পাতায় `assets` → `img` ফোল্ডারে ঢুকুন।
3. **Add file → Upload files** → ছবি টেনে দিন → **Commit changes**।

পুরোনো ছবি নিজে থেকেই বদলে যাবে।
